# 테오화랑 웹사이트

## ⚠ 올릴 때 주의

이 폴더 **안의 모든 파일과 폴더**를 저장소 루트에 올려야 합니다.
`index.html` 하나만 올리면 CSS와 이미지를 찾지 못해 서식 없는 화면이 나옵니다.

반드시 함께 올려야 하는 것:

    index.html
    assets/      ← CSS · JS · 파비콘  (없으면 화면이 깨집니다)
    images/      ← 사진
    about/  artists/  contact/  exhibitions/  guide/  visit/
    404.html  robots.txt
